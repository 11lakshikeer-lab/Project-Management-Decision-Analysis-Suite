# PMDecision – Software Project Management Decision Tool

PMDecision is an interactive web-based software engineering support application developed to assist in project estimation, prioritization, and managerial decision analysis.

### Live Demo: https://project-management-decision-analysi.vercel.app/

---

## Overview

This platform helps users perform structured software project planning activities through dedicated analytical modules.

Main supported functionalities include:

- Software effort and cost estimation
- Requirement prioritization
- Decision tree analysis
- Uncertainty handling
- Comparative project summary generation

---

## Features

- Interactive project input modules
- Decision-support based evaluation
- Prioritization and analysis dashboards
- Visual charts and structured reports
- Responsive frontend design
